# Session logs

This folder holds one log per working session (`session-01.md` … `session-NN.md`). Each log
records what was built, which decisions were taken **and why**, what was learned, the exact
TODO for the next session, and the reading assigned before it.

**These logs are written in Polish.** They are the project owner's learning journal — this
is a project built while learning the stack (FastAPI, React, TypeScript, SQL, Alembic, the
Poisson model), and the logs are the study notes that go with it. Translating them would
strip them of that purpose, so they stay in the language they were written in.

Everything meant to be read by someone else is in English:

* `../project-assumptions.md` — what is being built and why
* `../tools.md` — the stack and the reasoning behind each choice
* `../ROADMAP.md` — the plan, milestones and risks
* `../progres.md` — a condensed, chronological list of everything completed
* `../project-structure.md` — a map of every file and folder in the repo

If you want the short version of how the project evolved, read `../progres.md` — it is the
English summary of these logs.
